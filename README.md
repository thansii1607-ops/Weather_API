# AI Weather Assistant

AI Weather Assistant is a simple web application developed using Python and Streamlit. It helps users check the current weather information of different cities.

## Features

- Enter a city name and check the current weather
- Shows temperature
- Shows feels-like temperature
- Shows humidity
- Shows wind speed
- Shows precipitation
- Shows weather condition with emojis
- Supports common Indian cities
- Uses Open-Meteo API for weather data

## Technologies Used

- Python
- Streamlit
- Requests
- Open-Meteo API
